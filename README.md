## Project Overview
Presh's Hair Studio is a 5-page responsive website for a local hair and beauty salon in Soweto. The website provides information about services, prices, gallery, and a contact/enquiry form. The goal is to increase online bookings and showcase work.

## Website Structure
- `index.html` - The home page
- `about.html` - About page with company details
- `services.html` - Services offered
- `enquiries.html` - Enquiries page
- `contact.html` - Contact page with company contact details
- `gallery.html` - Images
- `_images/` - Images folder
- `css_assets/` - css files
- `js_assets/` - javascript files
- `_private/` - Documents

## Features
- 5-page navigation
- Responsive design for desktop, tablet and mobile
- Contact form and enquiry form
- External CSS styling
